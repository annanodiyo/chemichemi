# Chemichemi — Lake Victoria Fish Farmer Protector

**Vanilla Go | SQLite | HTMX | Tailwind CSS | Blockchain Ledger**

Protecting Kenyan Lake Victoria cage and beach seine fish farmers from low-oxygen fish kills and agricultural pollution.

## Quick Start

```bash
# 1. Initialize
go mod tidy

# 2. Run
go run .

# 3. Open browser
open http://localhost:8080

# 4. Select a beach (e.g., Mbita, Dunga, Usenge)
# 5. Click "Simulate Fish Kill" to see the early warning system in action
